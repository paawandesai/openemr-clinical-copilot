# USERS.md

The user document lives at [docs/USERS.md](docs/USERS.md) — the target user
(a primary care physician in the ~90 seconds between patients), their
workflow, and the three use cases the agent is designed for (Pre-Visit
Brief, Change Detection, Follow-Up Drilling), each with why an agent is the
right solution. Only the Pre-Visit Brief is built; Change Detection is not,
and Follow-Up Drilling exists only as a constrained single-turn follow-up
(build status in docs/USERS.md §3).
